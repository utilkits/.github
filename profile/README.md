# Utilkits

**99 everyday tools: PDFs, images, on-device AI, calculators, text and developer utilities. The PDF and image tools run in your browser, so those files stay on your device. No signup.**

- 🌐 Website: https://utilkits.com
- 🔍 What runs in the browser, what doesn't, and how to check: https://utilkits.com/how-it-works
- 🤖 For AI agents (beta): hosted MCP at https://apps.utilkits.com/agent and a REST API described at https://apps.utilkits.com/v1/openapi.json. Files sent to the Agent API are processed on Utilkits servers and expire after an hour.
- ✉️ Contact and bug reports: hello@utilkits.com

Built with Next.js, pdf-lib, pdf.js, qpdf (WebAssembly), Tesseract.js and Transformers.js.
